📝 Line Numbers Test - Option 3 (CSS Counter)

How Option 3 Works:

  • Uses CSS counter-increment to auto-number lines
  • Line numbers display via pseudo-elements
  • No JavaScript needed for numbering (only for toggle)
  • Each line must be wrapped in a separate element (e.g., <p>)
  • Works great for content that's already structured

Pros & Cons:

  • ✅ Pure CSS solution - elegant
  • ✅ No sync issues between scroll positions
  • ❌ Doesn't work with plain textarea (needs wrapped lines)
  • ❌ Requires converting textarea to contentEditable or other solution
  • ❌ More complex integration with current editor

Recommendation:

Option 3 is elegant but would require significant refactoring of the editor. Option 1 (Fake Line Numbers) would be better for our textarea-based editor as it requires minimal changes and works seamlessly.
