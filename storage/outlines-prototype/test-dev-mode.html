5. Manual Steps

  1. Open the app normally
  2. Create a root node (click "+ Add Node")
  3. Add a child (click "+" on the root node)
  4. Add a grandchild (click "+" on the child)
  5. Press Cmd+Shift+D (Mac) or Ctrl+Shift+D (Windows)
  6. Look for orange badges in the node footers
  7. Open browser console (F12) to see debug logs
